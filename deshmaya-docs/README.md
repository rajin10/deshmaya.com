# Deshmaya.com - Mockup-Based Laravel Build

Laravel implementation of the Deshmaya export website and admin dashboard, based on the supplied composite mockup. Final image replacement and visual sign-off remain open until approved photography and responsive design references are available.

## Docs (read in this order)
1. docs/PRD.md - what we are building and why
2. docs/PHASES.md - phase-by-phase tracker (single source of truth for progress)
3. docs/ARCHITECTURE.md - stack, folder structure, conventions
4. docs/DATABASE.md - tables and relations
5. docs/ADMIN_DASHBOARD.md - admin modules, settings keys, brand color system
6. docs/PERFORMANCE_AND_MEDIA.md - speed, 4K media, animation rules
7. docs/PAGE_WORKFLOW.md - how we build each page from design
8. docs/DECISIONS.md - open questions and decision log
9. docs/DEPLOYMENT_CPANEL.md - cPanel hosting notes
10. docs/PROGRESS_LOG.md - dated log, update after every work session
11. CLAUDE.md - short context file for AI assistants working in this repo

## Rule
Never start a new phase before the previous phase's Definition of Done is ticked in docs/PHASES.md.
